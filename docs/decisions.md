# Decision register

Implementation decisions made while building v0.1, with the evidence behind each. Numbered specifications (01–12) remain the design source of truth; entries here record where the implementation chose among allowed options or deviated.

| ID | Decision | Evidence or reason |
|---|---|---|
| D-001 | Python 3.13.15 accepted. | Install gate passed: nflreadpy 0.1.5, Polars 1.44, torch 2.14.0, FastAPI 0.141, scikit-learn 1.9 installed; one CPU train/save/load/infer cycle completed. Versions are locked in `uv.lock`. |
| D-002 | Raw assets are fetched directly from the nflverse release URLs that nflreadpy uses, not through its in-memory loaders. | Immutable byte storage with SHA-256 is required (02 §2). The GitHub release API's asset `updated_at` is recorded as `source_published_at` for the retrieved version. |
| D-003 | Historical tests use `reconstructed_conservative_delay`: PBP known 24h after estimated game end (kickoff + 4h), FTN charting 48h, participation on March 1 after the season (`configs/availability_policy.yaml`). | Only current re-uploads could be retrieved. FTN `date_pulled` is overwritten by re-pulls (every 2025 row shows September 2026), so it is not publication evidence. No result is described as an archived as-of replay. |
| D-004 | 2022 participation labels (NGS era) are excluded from coverage, man/zone and pressure cohorts. | The 2022 vocabulary differs (`PREVENT` present; `COVER_9`, `COMBO`, `BLOWN` absent) and the class mix shifts sharply (Cover 3 most common in 2022, Cover 1 in 2024). Consequence: 2023 coverage forecasts have no labeled history. |
| D-005 | FTN "not charted" zeros become null; pass-rusher counts above 11 are quarantined. | FTN has no nulls; kickoffs and punts carry `n_defense_box = 0` and `qb_location = "0"`. Two rows had impossible rusher counts (e.g. 45). |
| D-006 | Blitz (`n_blitzers >= 1`, provider definition) and `five_plus_rushers` stay separate labels. | They disagree on 6,760 of 82,598 charted dropbacks (8.2%). |
| D-007 | Coverage pooling rule: `COVER_9`, `COMBO`, `BLOWN`, `PREVENT` → `OTHER_OBSERVED`; raw values are kept in `coverage_raw`. | Rare classes (under 5% each); unknown stays masked and is never pooled. |
| D-008 | Training, profiles and the outcome cohort use regular-season plays only. | Keeps `reg_scrimmage_penalty_free_v1` consistent; postseason is a separate cohort not yet evaluated. |
| D-009 | Historical pregame cutoff = kickoff − 60 minutes. | Every target-game play shares one pregame context; the target game never enters its own history, priors or strengths. |
| D-010 | Per-play model inputs come only from fields in the request contract. | Timeouts and half clock are not requestable; the half clock is derived from quarter + quarter clock. Enforced by `test_situation_features_use_only_contract_fields`. |
| D-011 | No coordinator/playcaller registry is shipped; the coordinator prior component is unavailable and its weight is redistributed. | 05 §2 forbids manufacturing a staffing table. `configs/` can hold a sourced registry later. Schedules carry head coaches only. |
| D-012 | The served `pbp_baseline` Model B uses the `pbp` feature contract. `pbp_ftn` and `charted` contracts are evaluated as research comparisons. | 04 §1: a mode without charted heads uses a separately trained feature contract. |
| D-013 | Experiments are recorded as JSON ledgers in `artifacts/experiments/`, not MLflow. | Deviation from the 07 stack table to avoid a heavy dependency in v0.1; each record stores config, seeds, hardware, splits, all attempted models and the decision. |
| D-014 | Charts are accessible HTML/CSS bars paired with tables, not Recharts. | Provenance is encoded by texture (solid/hatched/dashed) and text, never color alone (09 §Accessibility). |
| D-015 | The Model B incumbent is chosen among servable baselines (ridge/logistic, gradient boosting). The situational table is a reported reference only. | A lookup-table predictor has no bundle format yet. |
| D-016 | Model A trains on Apple MPS; serving inference runs on CPU in evaluation mode without gradients. | Recorded in each experiment's hardware block. Reproducibility is promised within a tested environment only. |
| D-017 | `charted_history` shows coverage forecasts only when participation labels are published by the cutoff (prior seasons in-season). `enriched_current` is unavailable. | No lawful, timely current-season coverage source is approved. |
| D-018 | `blitz_probability` in the response is conditional on a dropback. | Blitz and rusher labels exist only on dropbacks; the explanation text states it. |
| D-019 | Split-conformal half-width uses the ⌈(n+1)(1−α)⌉-th smallest residual. | A unit test caught an off-by-one (the prior code took the next order statistic). |
| D-020 | Scouting-report intervals require at least 5 distinct games. | With 3 games the clustered bootstrap produced misleadingly narrow intervals (mean box ±0.01). |
| D-021 | Charting completeness is measured on games completed at least 48h (the documented FTN latency) before the cutoff; recent plays are reported as `charting_pending_recent_plays`. Audit method is part of the snapshot digest (`audit_v2_latency_aware`). | The first archived snapshot measured 71% FTN completeness for 2026 only because that day's games were in the denominator, which wrongly disabled box/blitz forecasts. |
| D-022 | Served bundle: `bundle_broad_v1_d3787de38384` from the pre-registered experiment `exp_20260927T201315`. Model A = prior mixture, Model B = gradient boosting (`pbp` contract). | Neither neural challenger passed the frozen gate. That run is the one whose 2025 test was opened first and reported once. |
| D-023 | Follow-up experiment `exp_20260927T203359` (prior-offset heads, zero-variance feature masking, clipped standardization) is exploratory. | It was motivated by development-window diagnostics (seasonal base-rate shift; constant coverage-history inputs in 2023). Its 2025 numbers are post-hoc, because 2025 had already been used. 2026 forward predictions are the next honest evaluation. |
| D-024 | Coverage and man/zone heads are marked failed for the served bundle (`configs/head_validation.yaml`); the API never displays them and returns `MODEL_UNAVAILABLE`. | 2025 coverage top-1 accuracy 24.1% is below the majority-class rate 27.8%. Man coverage predicted 45.6% vs 30.8% observed. |
